# Spotify Clone 🎵

A Spotify-inspired music streaming web interface built using HTML and CSS.

## Features
- Spotify-inspired user interface
- Sidebar navigation
- Music playlist and album sections
- Responsive layout (if implemented)

## Technologies Used
- HTML5
- CSS3

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/indrajithxd/spotify-clone.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
